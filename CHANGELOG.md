## [0.1.0] - 2026-09-15

### Added

- Serial terminal MVP: connect with full port configuration
  (baud rate, data bits, parity, stop bits, flow control)
- Hex & ASCII views, side-by-side mode
- Multi-tab port connections
- Real-time data plotting for incoming numeric data
- Quick macros for saved commands
- Signal control (RTS/DTR) and line-state monitoring (CTS/DSR/RI/CD)
- Light & dark themes (business / wireframe)
- CI (Rust tests, frontend build, typecheck) and multi-platform release workflow
