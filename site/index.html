Everything an embedded engineer needs

No bloat, no subscriptions. Just the tools you actually use when debugging serial devices.

Full Serial Control

Baud rate, data bits, parity, stop bits, flow control — every parameter, every time. Connect to any port on any platform.

Hex, ASCII & Binary

Toggle between views or see both side by side. DockLight-style hex dump when raw bytes tell the real story.

Signal Control

Toggle RTS/DTR, monitor CTS/DSR/RI/CD states. Hardware handshake without leaving the terminal.

Real-Time Data Plot

Visualize incoming numeric data as live charts. Perfect for sensor debugging and calibration.

Quick Macros

Save and trigger frequently-used commands. One click to send that AT sequence or boot command.

Multi-Tab

Open multiple port connections simultaneously. Debug firmware on one tab, monitor GPS on another.

Two editions, one engine

Pick the one that fits your workflow. Same serial core, different faces.

Install TUI

Get started in 3 steps

Pick your edition, install, connect.

  • Download Grab the binary for your OS
  • Install .dmg, .exe, .AppImage, or cargo install
  • Connect Pick a port, hit Connect, start debugging
GUI — macOS
# Download from GitHub Releases
$ open duckTerm-0.1.0.dmg
# Or via Homebrew (coming soon)
$ brew install --cask duckterm
TUI — Any Platform
# Install via cargo
$ cargo install duckterm-tui
# Or build from source
$ git clone && cargo build --release
