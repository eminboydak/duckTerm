# duckTerm

A free, open-source, cross-platform serial terminal application for embedded engineers and hardware developers.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Desktop framework | Tauri 2.x |
| Frontend framework | Svelte 5 |
| Styling | Tailwind CSS v4 |
| Component library | DaisyUI v5 |
| Font | JetBrains Mono |
| Serial communication | tauri-plugin-serialport |
